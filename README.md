# NeetCode Solutions in Java

My Java solutions to [NeetCode](https://neetcode.io) problems, synced automatically from NeetCode.io.

## What's here

Each problem has its own folder, and the submissions inside are my attempts in Java. Some problems have more than one submission, which shows my earlier tries before the final solution.

## Who this is for

If you're a beginner working through DSA in Java, you can use this repo to compare your approach with mine after you've tried a problem yourself. Trying first is where most of the learning happens.
